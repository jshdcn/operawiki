# 360浏览器

360浏览器由奇虎公司出品，最初由凤凰工作室代工，其[Windows](windows.md)版本市场占有率高居中国前茅。甚至有观察认为，IE已死Chrome未立之时，360浏览器一度摸到过中国第一。

与其原型[世界之窗](theworld.md)一样，360浏览器在Windows下也分为两个版本，IE和[Chromium](chromium.md)双核的称为“360极速浏览器”，单一[Trident](trident.md)内核的由于绑定了自身或外部的诸多安全服务，则称为“360安全浏览器”，从6.0版本开始也兼容了Chromium内核。不同的是，360浏览器的书签同步等自带服务绑定的是360帐号。

2011年后，凤凰工作室逐渐将主要精力转向360浏览器，并相继推出了[iOS](ios.md)和[Android](android.md)版。iOS平台另有一个支援[Firefox Sync](firefox-sync.md)的“360 Web Browser”，与之不是一个东西。

2016年360参与了Opera浏览器并购，一度获得27.5%股权，但并未发生技术交流。此后360自建团队接手，2018年推出[Linux](linux.md)版，开辟了信创浏览器赛道，2019年推出[macOS](macos.md)版，2024年推出鸿蒙版。

奇安信从360分拆后，也建立了自己的可信浏览器系列，与360浏览器形同镜像。但其主要面对政企市场，没有独立的个人帐号体系。

在安全浏览器和极速浏览器之外，2024年，360发布了第三条产品线“360AI浏览器”，脱胎于安全浏览器的代码基线，将以纳米为品牌的AI搜索和助手能力用于网页、文档及音视频内容的阅读与处理，可辅助总结信息和生成思维导图。
