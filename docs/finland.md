# 芬兰

芬兰（芬兰语：Suomi，瑞典语：Finland）是北欧国家，位于波罗的海东北岸，与[瑞典](sweden.md)、[挪威](norway.md)和[俄罗斯](russia.md)接壤，首都为赫尔辛基。

## 电信

[Telenor](telenor.md)于2019年收购芬兰运营商DNA 100%股权，由此进入并巩固芬兰市场，DNA成为Telenor在北欧全资控股的运营主体之一。

芬兰是[诺基亚](nokia.md)的诞生地。诺基亚作为长期主导全球手机市场的厂商，其Symbian等平台曾是Opera Mini、Opera Mobile的重要预装与分发渠道，对Opera在功能机与早期智能手机时代的全球扩张有显著影响。
