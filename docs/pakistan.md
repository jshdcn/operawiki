# 巴基斯坦

巴基斯坦是南亚的一个国家，位于[印度](india.md)西部。1947年根据蒙巴顿计划从英属印度独立。1967年迁都伊斯兰堡。1998年成为第一个拥有核武器的伊斯兰国家。

## 电信

[Telenor](telenor.md)在巴基斯坦于2004年开始运营，依靠预付费模式和农村覆盖快速抢占了重要的业务份额，成为当地的市场领导者。[中国移动](china-mobile.md)进军巴基斯坦市场时曾将其列为首选，但谈判破裂，因为这是Telenor在南亚地区的核心市场之一。

于是中国移动掉头收购了当地最小的运营商Paktel开始加大投资，奋力追赶，其他竞争对手也相继合并，Telenor巴基斯坦分公司作为盈利分部，显得后劲不足，市场份额从第1滑落至第3。Telenor考虑将其巴基斯坦业务出售给中国移动，但顾虑反垄断因素，最终无奈与Etisalat控股的Ufone合并。
