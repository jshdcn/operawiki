# C++

C++是一种通用的编译型程序语言，由丹麦计算机科学家比雅尼·斯特劳斯特鲁普（Bjarne Stroustrup）在贝尔实验室开发。它最初称为“带类的C”（C with Classes），后来加入虚函数、运算符重载等机制，并于1983年改名为C++。

C++以[C语言](c.md)为重要基础，同时提供面向对象、泛型和过程式等编程方式。它保留了对底层资源的直接控制能力，也提供类、模板和标准库等抽象工具，因此常用于系统软件、游戏、浏览器组件和高性能应用。C++与C有很大的语法和工具链渊源，但两者是不同的语言，C++并非严格意义上的C超集。

C++语言由ISO标准化，标准版本包括C++98、C++03、C++11及后续版本。使用C++开发的跨平台应用和界面工具包包括[Qt](qt.md)。
