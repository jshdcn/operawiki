# Aria

Aria是[Opera浏览器](browser.md)内置的[AI](ai.md)品牌，2023年5月24日由Opera公司发布。Opera称其为第一个原生集成于浏览器的AI，发布即可免费使用，覆盖180余个国家和地区，用户需登录Opera账户启用。

Aria基于Opera自有的Composer架构，连接OpenAI的GPT技术，并可结合网页实时结果作答。它既能像普通聊天AI一样检索信息、生成文本或代码，也掌握Opera全部支持文档，可以回答产品使用问题；能力通过侧边栏或命令行（Ctrl+/）调用。

Aria采取分批开放的策略：发布当天仅面向Opera One开发者版和Opera for Android测试版用户；6月20日随Opera One正式版上线；6月22日向全部Android用户开放；8月16日登陆iOS，覆盖Windows、Mac、Linux、Android和iOS全部主要平台，Opera称此时用户已超过100万。

2024年4月3日，Opera One开发者版开始实验性支持本地大语言模型，首批提供约150个变体、约50个模型家族，包括Meta的Llama、Vicuna、Google的Gemma、Mistral AI的Mixtral等。本地模型作为在线Aria的补充，推理在设备端完成，无需将数据发送至服务器，但每个变体通常需要2－10GB本地存储。同年5月29日，Opera宣布将本地AI能力从实验阶段推向Opera One和Opera GX旗舰版，此时支持的本地模型已超过2000个变体、60余个模型家族。
