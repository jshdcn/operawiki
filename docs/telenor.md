# Telenor

Telenor是[挪威](norway.md)的一家电信运营商，前身是挪威最早和最大的电信公司Telegrafverket，在1969至1995年间称作Televerket，之后易名Telenor至今，总部在离首都[奥斯陆](oslo.md)很近的城市福尼布。

## 历史

在1994至1998年间，Telenor是一家国有控股公司。在这段时间里，Telenor开始了它的国际化步伐。

现今，Telenor已经在[挪威](norway.md)、[孟加拉](bangladesh.md)（1997）、[丹麦](denmark.md)（2000）[瑞典](sweden.md)（2005）和[芬兰](finland.md)（2019）作为控股公司运营业务，在[马来西亚](malaysia.md)（1999）的移动公司也有重要份额。其中，挪威和孟加拉的公司都是当地的市场领导者。

Telenor历史上还曾在[乌克兰](ukraine.md)（1998-2019）、[泰国](thailand.md)（2000-2028）、[匈牙利](hungary.md)（2002-2018）、[黑山](montenegro.md)（1996-2018）、[巴基斯坦](pakistan.md)（2004-2025）、[塞尔维亚](serbia.md)（2006-2018）、[印度](india.md)（2009-2018）、[俄国](russia.md)（1994-2019）、[奥地利](austria.md)（1997-2007）、[斯洛伐克](slovakia.md)（1998-2005）、[捷克](czech.md)（1998-2005）、保加利亚（2013-2018）和[缅甸](myanmar.md)（2014-2022）等国运营业务，现已基本退出。

由于在人口众多的南亚地区占有重要份额，按用户数计算，远在2009年7月，Telenor曾拥有1.68亿手机用户，是世界第五大移动运营商。

## 产品

除了电信领域的全业务运营之外，Telenor还具有电台、数字电视频道的运营资质。旗下的Canal Digital是北欧最大的有线电视网。1992年至1995年间，公司还开发了一系列先进的信息技术，包括文件存储修复系统ODA和后来享有盛誉的浏览器[Opera](browser.md)。[Opera软件](asa.md)直至独立后很长时间都还在Telenor的办公室办公。

## 争议

Telenor的孟加拉分部是同当地著名的农民领袖[穆罕默德·尤纳斯](yunus.md)合作的Grameenphone，尤努斯指控Telenor违背协议，不肯将股权转让给孟加拉的穷人。

Telenor的[俄国](russia.md)分部是同阿尔法集团合资的VimpelCom，但在收购一家[乌克兰](ukraine.md)运营商的过程中，控股乌克兰KyivStar的Telenor与试图收购URS的阿尔法集团产生了矛盾。俄国[鄂木斯克](omsk.md)地方法院因而判决Telenor需出售VimpelCom股份以支付1.7亿美元罚款。

Telenor收购联科无线获得的[印度](india.md)业务与其[巴基斯坦](pakistan.md)分部产生了某种政治上的微妙关系，最终两块业务分别卖给Airtel和Etisalat。
