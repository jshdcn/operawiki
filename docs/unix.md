# UNIX

UNIX是一类多用户、多任务操作系统的统称，最初由贝尔实验室的肯·汤普逊（Ken Thompson）、丹尼斯·里奇（Dennis Ritchie）等人开发。项目始于1969年，早期版本以汇编语言编写；后来开发团队用[C语言](c.md)重写了系统的大部分代码，使UNIX更容易移植到不同硬件平台。

UNIX的设计强调简洁的工具组合、层次化文件系统和多用户环境。它的许多概念也影响了后来的操作系统及软件接口标准。POSIX标准规定了一组常见的操作系统接口，帮助不同系统上的程序保持兼容。

UNIX发展出多个系统分支，包括贝尔实验室的研究版本、商业UNIX，以及源自加州大学伯克利分校的BSD系列。许多现代系统具有类似UNIX的接口和设计，但并不一定是经过认证的UNIX系统。[Linux](linux.md)通常称为类Unix系统，而不是UNIX本身。
