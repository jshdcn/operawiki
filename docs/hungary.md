# 匈牙利

匈牙利位于中欧，是一个内陆国家，首都布达佩斯横跨多瑙河。多瑙河、蒂萨河与广阔的潘诺尼亚平原塑造了其地貌。9世纪末，马扎尔人进入喀尔巴阡盆地，约在公元1000年建立匈牙利王国。此后，匈牙利经历奥斯曼统治、哈布斯堡王朝和奥匈帝国时期。一战后独立，但国土大幅缩减。二战时加入轴心国，冷战时加入苏东阵营，2004年加入欧盟。匈牙利语属于乌拉尔语系，与周边多数语言差异显著。温泉浴场、民间音乐与舞蹈、以红椒调味的菜肴都是当地文化特色，炖牛肉汤（古拉什）尤为知名。

## 与Telenor的关系

[Telenor](telenor.md)于2002年收购匈牙利移动运营商Pannon GSM。2018年，PPF集团完成收购Telenor在匈牙利等中东欧市场的电信业务。2022年3月，该运营商更名为Yettel Hungary，继续在当地提供移动通信服务。
